# Agent Skills

Keep this repository small and composable.

- Put each skill in `skills/<skill-name>/` with `SKILL.md` and `agents/openai.yaml`.
- Keep skill names lowercase and hyphenated; keep frontmatter limited to `name` and `description`.
- Add each published skill to `README.md` and `.claude-plugin/plugin.json`.
- Validate every changed skill before committing.
