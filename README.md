# Agent Skills

Small, practical agent skills I use in real projects.

## Install

Codex and other agents:

```sh
npx skills@latest add ThiloReintjes/skills
```

Claude Code:

```text
/plugin marketplace add ThiloReintjes/skills
/plugin install thilo-skills@thilo-skills
```

## Skills

- [`codex-review`](skills/codex-review/SKILL.md) — Run Codex review loops on gpt-6.1-sol, optionally after a simplify pass, until no P0–P2 findings remain.
- [`crisp-writing`](skills/crisp-writing/SKILL.md) — Write clear, concise documents and presentation storylines that preserve evidence and voice.
- [`integrate-posthog`](skills/integrate-posthog/SKILL.md) — Add full-stack PostHog analytics, error tracking, session replay, and AI observability.
