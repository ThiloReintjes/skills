# Agent Skills

Small, practical agent skills I use in real projects.

## Install

Codex and other agents:

```sh
npx skills@latest add ThiloReintjes/skills
```

Claude Code:

```text
/plugin marketplace add ThiloReintjes/skills
/plugin install thilo-skills@thilo-skills
```
